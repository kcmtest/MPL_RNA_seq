Differential Expression Analysis

Where this session starts

flowchart LR
    A[Count matrix] --> C[Differential expression]
    B[Sample metadata] --> C
    C --> D[DESeq2]
    C --> E[edgeR]
    D --> F[Genes + statistics]
    E --> F

No external dataset is required

We will generate a synthetic RNA-seq count matrix and metadata inside R so every participant can run the full workflow locally.

Learning objectives

By the end of the session, participants should be able to:

  • generate a reproducible synthetic RNA-seq dataset;
  • create and validate metadata;
  • understand normalization and dispersion;
  • run differential expression with DESeq2;
  • run a comparable model with edgeR;
  • interpret log2 fold change, p-value and FDR;
  • create PCA, MA, volcano and heatmap visualizations;
  • compare the two frameworks conceptually.

Part 2 — Create Synthetic RNA-seq Data

Experimental design

We will simulate:

Feature Design
Samples 8
Control 4
Treated 4
Batches 2
Genes 1,000
Truly up-regulated genes 80
Truly down-regulated genes 80

The synthetic dataset includes biological variability, different library sizes and a balanced batch effect.

Create sample metadata

set.seed(2026)

metadata <- data.frame(
  sample = paste0("S", 1:8),
  condition = factor(
    rep(c("Control", "Treated"), each = 4),
    levels = c("Control", "Treated")
  ),
  batch = factor(
    rep(c("Batch1", "Batch2"), times = 4)
  )
)

rownames(metadata) <- metadata$sample

metadata

Expected structure:

   sample condition batch
S1 S1     Control   Batch1
S2 S2     Control   Batch2
...
S8 S8     Treated   Batch2

Create baseline expression

n_genes <- 1000
n_samples <- nrow(metadata)

gene_ids <- paste0(
  "Gene",
  sprintf("%04d", 1:n_genes)
)

base_mean <- exp(
  rnorm(
    n_genes,
    mean = log(80),
    sd = 1
  )
)

summary(base_mean)

This creates genes spanning low to high expression levels rather than giving every gene the same abundance.

Define truly differential genes

up_genes <- 1:80
down_genes <- 81:160

true_log2fc <- rep(0, n_genes)

true_log2fc[up_genes] <- 1.5
true_log2fc[down_genes] <- -1.5

table(true_log2fc)

Interpretation:

+1.5  → about 2.8-fold higher in Treated
-1.5  → about 2.8-fold lower in Treated
0     → no true condition effect

Add library-size differences

library_factor <- c(
  0.85, 1.05, 0.95, 1.15,
  0.90, 1.10, 1.00, 1.20
)

names(library_factor) <- metadata$sample

Different sequencing depths are normal. DESeq2 and edgeR estimate scaling factors so samples can be compared appropriately.

Add a small batch effect

batch_log2fc <- 0.25

batch_factor <- ifelse(
  metadata$batch == "Batch2",
  2^batch_log2fc,
  1
)

batch_factor

Because batch is balanced across conditions, it can be represented in the statistical model.

Simulate negative-binomial counts

dispersion <- runif(
  n_genes,
  min = 0.08,
  max = 0.35
)

count_matrix <- matrix(
  0L,
  nrow = n_genes,
  ncol = n_samples,
  dimnames = list(
    gene_ids,
    metadata$sample
  )
)

for (j in seq_len(n_samples)) {

  condition_effect <- if (
    metadata$condition[j] == "Treated"
  ) {
    2^true_log2fc
  } else {
    rep(1, n_genes)
  }

  mu <- base_mean *
    condition_effect *
    library_factor[j] *
    batch_factor[j]

  count_matrix[, j] <- rnbinom(
    n_genes,
    mu = mu,
    size = 1 / dispersion
  )
}

Part 4 — DESeq2 Workflow

Create the DESeq2 dataset

dds <- DESeqDataSetFromMatrix(
  countData = counts_filtered,
  colData = metadata,
  design = ~ batch + condition
)

dds

Why include batch?

~ batch + condition

asks for the condition effect after accounting for batch.

Run DESeq2

dds <- DESeq(dds)

Conceptually, this performs:

flowchart LR
    A[Counts] --> B[Size factors]
    B --> C[Dispersion]
    C --> D[Negative-binomial GLM]
    D --> E[Hypothesis testing]

Inspect normalization factors

sizeFactors(dds)

Compare with raw library totals:

colSums(counts_filtered)

DESeq2 does not simply divide every sample by the total count. It estimates relative size factors using the median-of-ratios strategy.

Variance-stabilizing transformation

vsd <- vst(
  dds,
  blind = FALSE
)

Use transformed values for:

  • PCA;
  • clustering;
  • heatmaps;
  • sample-level visualization.

Use raw counts for the DESeq2 statistical model.

PCA

Ask:

Obtain Treated vs Control results

res_deseq <- results(
  dds,
  contrast = c(
    "condition",
    "Treated",
    "Control"
  ),
  alpha = 0.05
)

summary(res_deseq)

Build a clean result table

deseq_df <- as.data.frame(
  res_deseq
) |>
  rownames_to_column("gene_id") |>
  mutate(
    status = case_when(
      !is.na(padj) &
        padj < 0.05 &
        log2FoldChange >= 1 ~ "Up",

      !is.na(padj) &
        padj < 0.05 &
        log2FoldChange <= -1 ~ "Down",

      TRUE ~ "Not significant"
    )
  )

table(deseq_df$status)

Compare estimated and true effects

Because this is synthetic data, we know the truth.

truth <- data.frame(
  gene_id = gene_ids,
  true_log2fc = true_log2fc
)

deseq_check <- deseq_df |>
  left_join(
    truth,
    by = "gene_id"
  )

cor(
  deseq_check$log2FoldChange,
  deseq_check$true_log2fc,
  use = "complete.obs"
)

Real datasets do not provide the true fold change. Synthetic data are useful because we can test whether the analysis recovers known signals.

Count recovered true DE genes

deseq_check <- deseq_check |>
  mutate(
    truth = case_when(
      true_log2fc >= 1 ~ "True Up",
      true_log2fc <= -1 ~ "True Down",
      TRUE ~ "True Null"
    )
  )

table(
  deseq_check$truth,
  deseq_check$status
)

Part 5 — edgeR Workflow

Create an edgeR object

dge <- DGEList(
  counts = counts_filtered,
  samples = metadata
)

Apply TMM normalization:

dge <- calcNormFactors(
  dge,
  method = "TMM"
)

dge$samples

Build the design matrix

design <- model.matrix(
  ~ batch + condition,
  data = metadata
)

design

The design matrix tells the statistical model how the samples relate to the experimental factors.

Estimate dispersion

dge <- estimateDisp(
  dge,
  design
)

plotBCV(dge)

edgeR estimates dispersion using information across genes.

Fit the quasi-likelihood model

fit <- glmQLFit(
  dge,
  design
)

Test the condition effect:

qlf <- glmQLFTest(
  fit,
  coef = "conditionTreated"
)

Extract edgeR results

edge_df <- topTags(
  qlf,
  n = Inf
)$table |>
  rownames_to_column(
    "gene_id"
  ) |>
  mutate(
    status = case_when(
      FDR < 0.05 &
        logFC >= 1 ~ "Up",

      FDR < 0.05 &
        logFC <= -1 ~ "Down",

      TRUE ~ "Not significant"
    )
  )

table(edge_df$status)

Part 6 — Compare DESeq2 and edgeR

Merge the results

comparison <- deseq_df |>
  select(
    gene_id,
    DESeq2_log2FC = log2FoldChange,
    DESeq2_padj = padj,
    DESeq2_status = status
  ) |>
  inner_join(
    edge_df |>
      select(
        gene_id,
        edgeR_log2FC = logFC,
        edgeR_FDR = FDR,
        edgeR_status = status
      ),
    by = "gene_id"
  )

Compare effect-size estimates

cor(
  comparison$DESeq2_log2FC,
  comparison$edgeR_log2FC,
  use = "complete.obs"
)

Scatter plot:

ggplot(
  comparison,
  aes(
    x = DESeq2_log2FC,
    y = edgeR_log2FC
  )
) +
  geom_point(
    alpha = 0.45
  ) +
  geom_abline(
    slope = 1,
    intercept = 0,
    linetype = 2
  ) +
  theme_classic()

Compare significant-gene overlap

deseq_sig <- comparison |>
  filter(
    DESeq2_status !=
      "Not significant"
  ) |>
  pull(gene_id)

edger_sig <- comparison |>
  filter(
    edgeR_status !=
      "Not significant"
  ) |>
  pull(gene_id)

length(deseq_sig)
length(edger_sig)

length(
  intersect(
    deseq_sig,

)

The packages will often agree strongly, but they are not expected to return perfectly identical gene lists.

DESeq2 vs edgeR — what differs?

Concept DESeq2 edgeR
Count model Negative binomial Negative binomial
Normalization Median-of-ratios TMM
Dispersion Trend + shrinkage Empirical-Bayes strategies
Common test Wald Quasi-likelihood / LRT
Complex designs Yes Yes
Input Raw counts Raw counts

Part 7 — Workshop Interpretation

What should participants report?

For each comparison, report:

  • contrast tested;
  • design formula;
  • number of genes tested;
  • number of significant genes;
  • significance threshold;
  • fold-change threshold;
  • PCA / sample QC observations;
  • top genes by effect and significance;
  • agreement between biological replicates;
  • software/package versions.

Common interpretation mistakes

Avoid these

  • using TPM/FPKM as DESeq2/edgeR count input;
  • interpreting raw p-values without FDR correction;
  • ignoring metadata order;
  • ignoring batch or paired structure;
  • treating every significant gene as biologically important;
  • removing an outlier only because it weakens the desired result.

Final Take-home Messages

1

Differential expression begins with correct counts and correct metadata.

2

DESeq2 and edgeR both model RNA-seq counts using negative-binomial frameworks.

3

Normalization corrects for sample-level scaling; dispersion captures biological variability.

4

Interpret effect size + uncertainty + sample-level patterns, not p-values alone.

5

Synthetic data let participants run the entire analysis without downloading external datasets.
