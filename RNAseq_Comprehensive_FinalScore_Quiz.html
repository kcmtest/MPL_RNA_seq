Section 1 — RNA-seq Foundations

1. What does bulk RNA-seq primarily measure?

  • The relative abundance of RNA-derived sequencing fragments across a biological sample
  • The exact number of intact RNA molecules in every cell
  • Only DNA sequence variants
  • Protein abundance directly

2. Which are important RNA-seq library-design choices?

Select all that apply.

  • Poly(A) selection versus rRNA depletion
  • Stranded versus unstranded library preparation
  • Single-end versus paired-end sequencing
  • The color used for the PCA plot

3. Why are biological replicates important?

  • They capture biological variability and support inference beyond a single specimen
  • They make FASTQ quality scores larger
  • They eliminate all batch effects automatically
  • They replace the need for metadata

4. Which situation represents confounding?

  • All controls are processed in Batch 1 and all treated samples in Batch 2
  • Controls and treated samples are balanced across both batches
  • Each condition contains independent biological replicates
  • Sample metadata record both condition and batch

Section 2 — FASTQ and Quality Control

5. What information is contained in a FASTQ record?

  • Read identifier, nucleotide sequence and per-base quality information
  • Gene counts and adjusted p-values
  • Only chromosome coordinates
  • Gene Ontology categories

6. What does a Phred Q30 base quality indicate?

  • An estimated base-call error probability of about 0.001
  • A 30% probability that the base is wrong
  • A mapping quality of exactly 30
  • Thirty reads mapped to one gene

7. Which are typical raw-read QC checks?

Select all that apply.

  • Per-base sequence quality
  • Adapter content
  • GC distribution
  • Adjusted p-value distribution

8. A FastQC warning should generally be interpreted as what?

  • A diagnostic signal that should be interpreted in the context of the library and experiment
  • Proof that the sample must be deleted
  • Proof that alignment will fail
  • Evidence that DESeq2 normalization is wrong

Section 3 — Alignment and Reference Files

9. Why does RNA-seq usually require a splice-aware aligner?

  • RNA-derived reads can span exon-exon junctions that are separated by introns in the genome
  • RNA reads never contain sequencing errors
  • RNA-seq does not use a reference sequence
  • Every RNA read maps to several chromosomes

10. What is the main role of a reference FASTA?

  • To provide the nucleotide sequence against which reads are aligned
  • To describe gene and exon coordinates
  • To store sample condition labels
  • To contain differential-expression statistics

11. What is the main role of a GTF/GFF annotation?

  • To describe genomic features such as genes, transcripts and exons
  • To store compressed raw reads
  • To contain only base-quality scores
  • To replace the reference genome sequence

12. Why must FASTA and GTF/GFF versions be compatible?

  • Their genome build and chromosome coordinate system must refer to the same reference
  • Both files must contain identical text
  • Both must have the same file extension
  • DESeq2 requires both files directly

13. What does a high MAPQ generally represent?

  • Greater confidence in the genomic placement of the read
  • Greater confidence in every nucleotide base call
  • A larger gene fold change
  • More enriched pathways

14. What commonly causes multi-mapping?

Select all that apply.

  • Repetitive genomic sequence
  • Highly similar paralogous genes
  • Pseudogenes with sequence similarity
  • Using an adjusted p-value threshold

Section 4 — SAM/BAM and Counting

15. What is the key difference between SAM and BAM?

  • BAM is a compressed binary representation of SAM alignment information
  • SAM stores genes while BAM stores proteins
  • SAM is RNA-only and BAM is DNA-only
  • BAM is an annotation format

16. In 50M1000N50M, what does the N represent in RNA-seq?

  • Reference sequence skipped by a spliced alignment, commonly an intron
  • A base with an unknown quality score
  • A duplicated read
  • A gene with no expression

17. Which operations are commonly performed with SAMtools?

Select all that apply.

  • Sorting alignment files
  • Indexing BAM files
  • Viewing and filtering alignment records
  • Performing GO over-representation analysis

18. Why is coordinate sorting useful?

  • It places alignments in genomic order and supports efficient indexed access
  • It alphabetically sorts gene symbols for enrichment
  • It normalizes library sizes
  • It calculates p-values

19. What does featureCounts conceptually do?

  • Assigns aligned reads or fragments to annotated genomic features
  • Performs splice-aware alignment from FASTQ
  • Performs differential-expression hypothesis testing
  • Builds a genome FASTA

20. Which factors can change feature assignment?

Select all that apply.

  • Library strandedness
  • Single-end versus paired-end counting rules
  • Ambiguous overlap with multiple genomic features
  • Volcano-plot point size

Section 5 — Count Matrix and Statistical Modeling

21. What should DESeq2 or edgeR typically receive as expression input?

  • Raw integer-like gene counts
  • Only TPM values
  • Only FPKM values
  • Only z-scores

22. Why not compare raw counts directly between samples?

  • Observed counts are influenced by library size, sampling and biological variability
  • Raw counts cannot contain zeros
  • Raw counts are always normally distributed
  • Raw counts already represent adjusted p-values

23. What is the null hypothesis for a standard gene-level condition test?

  • There is no systematic condition effect on expression for that gene
  • The gene has exactly zero reads in all samples
  • Every sample must have identical counts
  • All genes are differentially expressed

24. Why is the negative binomial model useful for RNA-seq?

  • It can represent count data with variability greater than expected under a simple Poisson model
  • It assumes every gene has the same count
  • It converts BAM files to FASTQ
  • It performs pathway annotation

25. What does dispersion represent conceptually?

  • Extra variability in counts around their expected mean
  • The chromosome position of a gene
  • The number of GO terms assigned to a gene
  • The proportion of mapped reads

26. Why do methods borrow information across genes when estimating dispersion?

  • Gene-wise variability estimates can be unstable, especially with limited replicates
  • All genes are assumed to have identical expression
  • It removes the need for biological replicates
  • It guarantees every gene becomes significant

Section 6 — DESeq2 and edgeR

27. Which pairing correctly matches common normalization strategies?

  • DESeq2: median-of-ratios; edgeR: TMM
  • DESeq2: TMM; edgeR: TPM
  • DESeq2: FPKM; edgeR: RPKM
  • DESeq2: quantile normalization; edgeR: z-score scaling

28. What do DESeq2 and edgeR have in common?

Select all that apply.

  • They model gene counts using negative-binomial frameworks
  • They estimate dispersion for RNA-seq count variability
  • They support generalized linear-model designs
  • They require TPM as the statistical model input

29. Which testing strategies are correctly associated with the packages?

Select all that apply.

  • DESeq2 commonly uses Wald tests for coefficients and contrasts
  • DESeq2 supports likelihood-ratio tests for nested models
  • edgeR supports quasi-likelihood inference
  • edgeR performs differential expression only with a t-test

30. What is the main difference between effect size and statistical evidence?

  • Effect size describes the magnitude of change; p-values describe evidence against a null model
  • They are two names for the same number
  • Adjusted p-value indicates whether expression increased or decreased
  • Effect size depends only on the number of tested genes

Section 7 — Multiple Testing and Interpretation

31. Why is multiple-testing correction required?

  • Testing thousands of genes creates many opportunities for chance-positive results
  • It increases every fold change
  • It changes FASTQ quality scores
  • It improves genome alignment

32. What does an FDR-controlled adjusted p-value help control?

  • The expected proportion of false discoveries among reported discoveries under the procedure
  • The probability that every significant gene is biologically important
  • The fraction of reads that map uniquely
  • The number of transcripts in the annotation

33. Which result deserves the most careful interpretation?

  • A statistically significant gene with a very small effect size
  • A gene whose sample-level pattern agrees with the modeled contrast
  • A pathway supported by several coherent genes
  • A result that is consistent across independent replicates

Section 8 — Visualization and Functional Analysis

34. What is PCA mainly used to assess in RNA-seq?

  • Global sample relationships and major sources of expression variation
  • The exact CIGAR string of each read
  • Gene Ontology term definitions
  • FASTQ adapter sequences

35. What does an MA plot combine?

  • Mean abundance and log fold change
  • Mapping quality and base quality
  • GO term size and pathway score
  • Chromosome and genomic position

36. What does a volcano plot emphasize?

  • Effect size together with statistical evidence
  • FASTQ quality versus GC content
  • Genomic position versus MAPQ
  • Transcript length versus exon count

37. What is the core difference between ORA and GSEA?

  • ORA uses a selected gene list; GSEA evaluates genes along a ranked list
  • ORA uses FASTQ and GSEA uses BAM
  • ORA performs alignment and GSEA performs counting
  • ORA is only for DNA-seq

38. Why does the ORA background matter?

  • It defines the gene universe against which enrichment is evaluated
  • It determines FASTQ compression
  • It replaces the selected significant gene list
  • It sets BAM coordinate order

39. Why can analyzing up- and down-regulated genes separately be useful?

  • Opposing biological programs can be obscured when both directions are combined
  • It makes alignment splice-aware
  • It changes base quality scores
  • It guarantees significant enrichment

40. Which sequence best represents a defensible RNA-seq interpretation workflow?

  • Technical QC → sample relationships → correct contrast → gene-level effects → pathways → biological context
  • GO enrichment → FASTQ QC → alignment → experimental design
  • Volcano plot → sequencing → RNA extraction → hypothesis
  • Adjusted p-values → library preparation → sample metadata
